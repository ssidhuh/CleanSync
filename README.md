# CleanSync – Intelligent Cleaning Service Management System

CleanSync is a modern desktop application developed using Python and Object-Oriented Programming principles for managing cleaning company operations.

The application provides an integrated system for managing customers, cleaners, bookings, schedules, invoices, and payments through a modern graphical user interface.

---

# Features
## Dashboard
- Business statistics overview
- Revenue analytics
- Booking status charts
- Recent bookings activity

## Customer Management
- Add, edit, delete customers
- Customer search functionality
- Customer information storage

## Cleaner Management
- Manage cleaner profiles
- Availability tracking
- Cleaner scheduling support

## Service Management
- Create and manage cleaning services
- Service pricing management
- Specialized service categories

## Booking System
- Create and manage bookings
- 24-hour time scheduling
- Booking status tracking
- Cleaner assignment

## Weekly Schedule
- Weekly calendar overview
- Cleaner filtering
- Booking visualization
- Schedule navigation

## Invoice Management
- Automatic invoice generation
- Auto-filled booking service line items
- Tax and subtotal calculation
- Invoice status tracking

## Payment Management
- Payment recording system
- Automatic payment reference generation
- Invoice-payment integration
- Payment status tracking
